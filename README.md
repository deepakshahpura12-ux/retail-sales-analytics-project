# 📊 Retail Sales End-to-End Data Analytics Project

## 🚀 Project Overview
This project is an end-to-end data analytics solution built using **Excel, Power Query, SQL (PostgreSQL/BigQuery), and Power BI**. The objective is to analyze global retail sales performance, track revenue trends, evaluate cancellation risks, and uncover top-performing products to drive data-backed business decisions.

---

## 🛠️ Tech Stack & Tools Used
* **Data Cleaning & Transformation:** Microsoft Excel, Power Query
* **Database & Advanced Querying:** SQL (Performed 25+ complex queries, window functions, and aggregations)
* **Visualization & Dashboarding:** Power BI Desktop (Dark Theme UI)
* **Version Control:** Git & GitHub

---

## 🔄 Project Workflow
1. **Data Extraction:** Downloaded raw retail transaction dataset from Kaggle.
2. **Data Cleaning (Excel & Power Query):** Handled missing values, corrected data types, removed duplicates, and structured date formats.
3. **Database Management (SQL):** Imported cleaned data into SQL, performed data transformations, engineered calculated columns, and ran 25+ analytical queries to extract deep business insights.
4. **Data Visualization (Power BI):** Connected SQL database to Power BI, built custom measures, designed an interactive dark-themed dashboard, and implemented dynamic filters (Country, Transaction Type, Product Description, Date Range).

---

## 📈 Key Dashboard Metrics & Visuals
* **KPI Header Cards:** Total Revenue (£8.28M), Total Orders (22.18K), Unique Customers (4K), and Average Order Value (£20.62).
* **Geographical Analysis:** Dark-themed World Map highlighting sales distribution across countries.
* **Transaction Breakdown Donut Chart:** Visualized successful completed sales (93.59%) vs. cancelled/returned orders (6.41%).
* **Top Products Bar Chart:** Identified highest-revenue generating products using Top N filters.
* **Monthly Revenue Trend Line Chart:** Tracked seasonality and growth spikes across months (Dec 2010 - Dec 2011).

---

## 💡 Key Business Insights & Recommendations
* **Revenue Peak:** Sales experience a massive surge during the final quarters, indicating strong seasonal/festive demand.
* **Cancellation Impact:** ~6.4% revenue leakage due to cancellations/returns requires immediate supply chain and product quality audits.
* **AOV Optimization:** Implementing bundle pricing can successfully increase the current Average Order Value (£20.62).
